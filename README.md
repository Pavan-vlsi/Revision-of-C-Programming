# C Programming Revision

## About This Repository

This repository documents my journey of revising and strengthening
my C programming fundamentals through conceptual learning, practical
implementation, problem-solving, and testing.

I am revisiting the concepts I previously studied, identifying gaps
in my understanding, and applying my knowledge by writing and
executing C programs using Visual Studio Code (VS Code).

The objective is not merely to memorise syntax, but to understand
programming concepts, develop logical thinking, and improve my
ability to implement, analyse, debug, and test programs independently.

## Learning Approach

For each topic, I aim to:

- Understand the underlying concepts.
- Prepare concise notes for future reference.
- Implement relevant programs in C.
- Execute programs and verify their outputs.
- Practise problem-solving and debugging.
- Document my progress through meaningful GitHub commits.
